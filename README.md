# Pixel & Druck

**Bilder vorbereiten. Druckgrößen verstehen. Dateien lokal verarbeiten.**

Ein kostenloses Hobbyprojekt von [rud5vision](https://github.com/rud5vision), derzeit in Entwicklung.

Pixel & Druck verbindet kleine Bildwerkzeuge in einer gemeinsamen Oberfläche. Bilddateien werden auf dem eigenen Gerät im Browser verarbeitet; die Werkzeuge laden sie nicht auf einen Server hoch.

## Werkzeuge

| Aufgabe | Möglichkeiten |
| --- | --- |
| Druck vorbereiten | Druckformat und PPI wählen, Ausschnitt oder Ränder prüfen, Datei herunterladen |
| Wallpaper erstellen | Monitor- und Bildschirmformate, eigene Pixelmaße, Crop/Fit und Zoom |
| Dateien konvertieren | Unterstützte Bilddateien umwandeln, Pixelmaße beibehalten oder gezielt ändern |
| GIF & Animation | Unterstützte GIF-/WebP-Animationen ansehen, kürzen, skalieren und als GIF speichern |
| PDF & Ebenen | PDF-Seiten auswählen; unterstützte Krita-/OpenRaster-Rasterebenen einzeln verwenden |
| Maße verstehen | Pixel, Zentimeter, Millimeter und Zoll umrechnen; PPI an Beispielen vergleichen |

Zwölf Sprachfassungen, automatische Sprachwahl und System-/Hell-/Dunkel-Darstellung sind vorhanden. Piko öffnet Hilfe und einen lokalen Feedbackentwurf.

## Projektstand

**Version 0.15.4 · 01.10.2026**

Die Werkzeuge sind lokal umgesetzt. Eine öffentliche Tool-Adresse ist noch nicht freigeschaltet; sie wird hier nach der Veröffentlichung ergänzt. Dieses Repository ist zunächst die Projektvorstellung. Es enthält derzeit weder den vollständigen Anwendungscode noch eine online ausführbare Version.

Ein Videokonverter mit Zeitleiste ist eine Ausbauidee und noch nicht enthalten.

## Gut zu wissen

- Originaldateien werden nicht verändert. Downloads entstehen als neue Dateien.
- Große Dateien können Browser und Arbeitsspeicher überfordern. Kleine Vorschauen und Warnungen reduzieren das Risiko, garantieren aber nicht die Verarbeitung auf jedem Gerät.
- Die Bildausgabe ist derzeit auf 128 Megapixel und 16.000 Pixel je Kante begrenzt; Browser können früher an Grenzen stoßen.
- PDF-Rasterexport und Ebenenexport erhalten nicht sämtliche Originaleigenschaften. Druckfarben, Masken, Mischmodi und Formatvarianten haben eigene Grenzen.
- Lokale Dateiverarbeitung bedeutet nicht, dass der Abruf einer später gehosteten Website ohne technische Verbindungsdaten erfolgt.
